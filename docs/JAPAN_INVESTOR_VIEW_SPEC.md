# 日本株 投資家向け市場理解ビュー仕様 v2

## 目的

日本株ページを、ランキングの列挙ではなく「一目で強弱 → 理由 → 詳細数値」の順で読む市場理解ビューとする。スマートフォンでは冒頭約3秒で今日の強弱をつかめる構成を優先する。

1. 今日の市場観
2. 海外から日本株への主要材料（材料 → 伝達経路 → 影響業種）
3. 市場内部の強弱
4. どちらが強い？（値動きから見たローテーション）
5. 強い／弱いセクターの勢い・広がり・商い・継続力
6. 注目銘柄
7. 昨日のシナリオ検証 → 今日への修正
8. 今後の監視ポイントと見方の変更条件

## データ負荷の区分

### Tier 1：既存データだけで実装

- `market.json`：ドル円、米10年金利、米国半導体株、原油、金、銅など。固定枠ではなく日本株への影響度順に最大4件を選ぶ。
- `japan-market.json`：TOPIX-17業種ETF、主要監視34銘柄、指数連動ETF、価格、出来高
- `japan-stocks.json`：朝の注目業種、未反映材料

今回の本番実装はTier 1に限定する。ページ表示時の外部API・AI呼び出しは追加しない。

### Tier 2：軽微な追加取得で実装可能

- Growth/Value指数
- 小型株指数
- 日本の半導体専用指数またはETF

### Tier 3：新規API・AI処理が必要

- 投資主体別リアルタイム資金フロー
- ニュース因果の自動生成
- 類似局面の大規模バックテスト

Tier 2・3は今回の対象外とする。

## 判定規律

- 実測値は`observed`、分類や相対比較は`estimated`、信頼できる系列がない軸は`unavailable`とする。
- Growth/Value、大型/小型、日本株半導体は現行データで無理に方向判定しない。
- 外需/内需と景気敏感/ディフェンシブは固定業種ETF群の代理比較であり、分類を`basis`に明記する。
- ローテーションは投資主体別売買ではないため「値動きから見たローテーション（推定）」と呼ぶ。「資金流入」と断定しない。表示順は比較結果、差、詳細数値とする。
- セクターの広がりは全構成銘柄ではなく主要監視2銘柄の限定評価と明記する。
- セクター4軸の計算規則と元数値を表示し、根拠のない総合点・総合戦闘力は算出しない。
- 金と銅は固定表示しない。原油・銅の継続先物は、中国実需や限月付き清算値として扱わない。
- 海外ドライバーの日付が日本株現物の市場日より新しい場合は「日本株現物に未反映」とする。
- 朝の確認では、休場をデータ異常と混同しない。休場日は前営業日の現物データを保持し、休場状態と次の取引日に持ち越す監視点を明示する。
- 日付不一致はデータ異常として「昨日のシナリオ検証 → 今日への修正」を保留する。

## 将来拡張

履歴分析では、現行の`market_regime`、`rotation_read`、`sector_quality`を日付別に保存し、同一定義のまま比較できるようにする。今回は類似局面検索やバックテストを実装しない。
