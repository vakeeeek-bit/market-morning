# 空欄・欠測監査（2026-10-19）

## 修正済み

| 項目 | 原因 | 対応 |
|---|---|---|
| 今日以降の重要イベント | `report.events` を日次生成する処理がなかった | 公式日程を保持する台帳と14日窓の更新処理を追加。JST、予想・前回値、注目理由、影響市場、出典を検証 |
| 朝シナリオの検証点 | 寄り付き前・休場・取得保留時に `checks` を空配列へ置換 | 各状態で「大引け後に確認」「次回取引日に確認」等を明示 |
| 市場レジーム詳細 | `dimensions` が固定の空配列 | 同一市場日の指数・業種ETFで5軸を生成し、画面にも表示 |
| 米2年・10年金利差 | DGS2とYahooの10年金利を混在させ、基準日不一致で欠測 | 2年・10年をFRED DGS2/DGS10に統一。同一公表日の場合だけ計算 |
| 個別株ニュースの取得状態 | 空配列の意味が画面とデータで曖昧 | 一次情報確認済み記事を保持し、確認範囲・件数を明示する正規化処理を追加 |
| 一般的な空表示 | 汎用描画関数が空配列を無表示にした | 「未取得または該当なし」と品質情報への案内を表示 |

## 意図的に非表示・除外

| 項目 | 理由 | 代替表示 |
|---|---|---|
| 未確認のイベント予想・前回値 | 推測禁止 | `未確認` と表示 |
| アナリスト評価変更の全件一覧 | 契約データ未導入で無料公開情報の網羅性を保証できない | 取得状態、確認元、網羅範囲を表示し、「変更なし」と断定しない |
| Gold / WTI / Brentを用いた確定的な結論 | 限月・値種別・基準時刻・証跡の確認不足 | 数値は注記付き、総合結論から除外 |
| `important_stories` / `other_stories` の空配列 | 確認済み3件を `top_stories` に集約済み | 個別株ニュース監査件数を表示 |
| 市場レジームの乖離警告 `null` | 日経平均とTOPIXが逆方向ではない | 警告を表示しない |

## 未解決

| 項目 | 制約 | 次の対応主体 |
|---|---|---|
| アナリスト評価変更の完全網羅 | QUICK/IFIS等の契約データが必要 | サイト運用者が契約APIを導入後、取得アダプターを追加 |
| 先物3商品の完全な観測証跡 | 現行Yahoo継続先物では限月・清算値の正本性が不足 | サイト運用者が取引所または契約データを導入 |
