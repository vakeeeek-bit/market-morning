# 収集継続と公開の区別

総合公開ゲートの欠測は総合レポートの公開を保留する理由であり、調査を終了する理由ではない。

各未確認項目について公式本文、現行掲載ページ、同ページが利用する公開データの順に確認する。取得できない場合は試したURL、確認日時、応答、残る不足を記録する。「新規材料なし」は確認した主体と期間に限定する。

確認済みニュースはニュース専用検証を実行し独立公開できる。総合レポート、ニュース、市場データの基準日と品質表示は区別する。市場数値を別資料で置換したり、連続先物の限月を推定して総合ゲートを通してはならない。

過去日は後日収集として保存し、当時の朝に確認済みだったと扱わない。未完成の総合候補も、確認済みの事実、正本の同日比較、条件付き日本株への波及を記述し、欠測だけを理由に分析全体を空欄にしない。
